Challenge 20.1 Reflection Questions

What are the two required arguments for setTimeout()? The function to run and the delay in milliseconds.

How do you cancel a timeout before it executes? Save its ID and pass that ID to clearTimeout().

Is setTimeout blocking or non-blocking? It is non-blocking because the rest of the code continues running.

Chapter 20.2: Navigation links scroll smoothly and stop below the sticky navigation bar. The progress bar at the top fills as you scroll.

Challenge 20.2 Reflection Questions

What does event.preventDefault() stop from happening? It stops the browser's normal action, such as jumping immediately to an anchor.

What is the difference between window.scrollTo() and element.scrollIntoView()? window.scrollTo() scrolls to page coordinates, while scrollIntoView() scrolls until a chosen element is visible.

Can you control the scroll speed with native methods? Native smooth scrolling lets the browser choose the animation speed; it does not provide a speed setting.

Chapter 20.3: Use the print button to print this portfolio or save it as a PDF. The resume button prints a clean resume summary.

Challenge 20.3 Reflection Questions

What does window.print() open? It opens the browser's print dialog.

Can you customize the print layout with CSS? Yes, using an @media print stylesheet.

What happens to position: fixed elements when printing? Their display and placement can differ in print output, so this page hides its fixed controls when printing.

Chapter 21: Interact with the Document

These features use the DOM to create project cards, respond to message input, and highlight the current navigation section.

Challenge 21.1: Dynamic Project Rendering

The project cards above are built from the projects array using document.createElement() and appended to the projects container.

Challenge 21.1 Reflection Questions

What is the difference between innerHTML and createElement? innerHTML reads or replaces HTML using a text string, while createElement makes a new element that JavaScript can change and add to the page.

Which is safer against XSS attacks? createElement with textContent is safer because it treats user-provided text as text instead of running it as HTML.

Can you attach event listeners to elements created with createElement? Yes. You can use addEventListener() on a new element before or after adding it to the page.

Challenge 21.2: Live Character Counter

The message box shows how many characters have been typed and changes its counter color near the limit.

Challenge 21.2 Reflection Questions

What is the difference between input and change events? The input event runs every time the value changes, while change usually runs after the user finishes editing the field.

Does input fire for paste actions? Yes. Pasting text changes the value, so the input event runs.

How do you get the remaining characters instead of used characters? Subtract the current value length from the maximum, such as 500 - message.value.length.

Challenge 21.3: Active Navigation Highlighting

The navigation link for the section currently on screen is highlighted with an underline.

Challenge 21.3 Reflection Questions

What is the difference between scrollY and pageYOffset? They both return the number of pixels the document has scrolled vertically. pageYOffset is the older alias.

Why subtract 100 from offsetTop? It helps account for the sticky navigation so the section is treated as active before it moves underneath the navigation.

What is event throttling, and why might you need it here? Throttling limits how often a scroll handler runs, which can reduce extra work while scrolling.
